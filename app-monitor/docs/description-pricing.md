# 描述判价规则

当前产品以 iPhone 采集为唯一运行入口。规则位于“监控规则 → 判价”，判价依据位于“运行记录 → 成色与扣费依据”；不新增独立智能评估页。

## 判价链路

1. 机型搜索一次，在结果页切换容量并确认，优先继承首页地区，核对后跳过重复地区筛选。只采集新发。
2. 列表初筛使用该机型容量、所选报价类别中允许成色的最高回收价，加允许议价金额；不预先锁定某个成色。低价比例和有歧义的关键词留到详情判断。
3. 对候选进详情，等待正文和唯一可确认的实际售价加载，直接按详情判断机型、容量、成色与扣费，不要求正文包含列表摘要，也不要求售价等于列表旧价。保存、判价和通知均使用实际详情，无需先找到分享入口。明确不符合者直接返回，运行记录保留判价拒绝原因与扣费参考，不归类为取链接失败。待确认继续取链接，提前计算异常时也继续原流程。
4. 对可继续者读取卖家名称和鱼小铺标识、复制官方分享链接，取得真实ID后正式评估。金额只能来自报价记录；模型不能自行估计金额。未取得链接的只记录，不推送。优先读取本次可见复制确认框，无法读取时才准备剪贴板标记并重新复制。
5. 只有启用 AI 且配置连接时，才把本地符合或待确认的候选做二次复核；本地明确不符合的不调用模型。
6. 按商品ID去重后通知。待确认默认也通知，保留状态，原因在网页查看；之后升级为明确符合可以再通知一次。旧版本已成功推送的商品不因切换规则重复推送。

运行记录将「未完成」与「不符合」分开：正文/售价缺失为「详情读取失败」；本地判价符合或待确认后取链接失败为「链接获取失败」，原因注明已完成的判价阶段；尚未完成判价的历史无链接记录为「核验未完成」。没有真实商品链接仍不推送。分享期间切换应用只与已读详情快照核对，不与列表摘要比较。

## 信息缺省口径

| 描述 | 处理 |
| --- | --- |
| 未说明电池、拆修、水印等 | 默认正常，不扣费，不仅因缺失标待确认；事实中仍保留“未说明”，不会写成100%电池或已证明无拆修 |
| 99新、几乎全新、无明显划痕 | 初判靓机 |
| 99新，同时有轻微划痕 | 具体瑕疵优先，按小花 |
| 无拆修，未说明成色 | 不因此判靓机，成色待确认 |
| 成色无法判定 | 默认以同机型容量的小花报价为参考，扣除明确适用费用后保留待确认；没有可用小花报价则不估价，不回退靓机价 |
| 无水印、无拆无修 | 否定描述，不触发相应故障扣费 |
| 图片有水印 | 不当成屏幕水印 |
| 明确电池78% | 按报价中的健康度条件扣费；不能把循环100次当健康度100% |
| 新原装电芯、换过电芯 | 识别为电池更换，按同机型适用扣费处理；「原装电芯」不代表已确认官方整块电池，普通原装电芯或100健康本身不推断更换 |
| 明确换屏等异常，但没有可确定的适用备注 | 该项按0扣费，保留已有扣费，继续按对应成色价加议价空间判断；未知成色按小花参考 |
| 屏幕水印、碎屏、功能故障、锁机 | 默认不收，可修改明确不收问题配置 |

关键词按最长词组和更具体的瑕疵处理，例如“轻微磕碰”不会同时命中通用“磕碰”而重复降档。不同位置的瑕疵取更差档位。仅根据卖家文字判断，不能证明真实成色。

## 报价与扣费

`推送上限 = 对应成色回收报价 − 适用扣费 + 允许议价金额`

例如靓机报价5200，明确电池78%，当日报价写低于80%扣300，允许议价200：调整后回收价4900，挂牌价5100以内可推送。没写电池则不扣这300，上限为5400。

成色未能确定时，详情参考基准改用小花价，不使用允许档位的最高价；仍保留「成色待确认」并明确标注「小花参考」，不把参考档位保存为已识别成色。明确识别成色或有明确降档规则时继续使用实际档位。列表初筛继续采用允许档位最高价以免漏掉靓机，进入详情后才按小花回退规则收紧上限。计价版本变化会重新计算评估、保留旧记录，并继续复用可用的事实缓存。

明确、受支持的备注自动识别，例如电池低于80%、换屏、换电池、颜色差价、后盖破当大花收。不支持的复杂备注在规则中核对后启用；备注文本变更会重新识别，单纯金额更新保留原触发条件。未识别的电池备注先核对实际条件：75%不会触发低于70%的备注，未提及鼓包不会仅因写了健康度就触发电池鼓包备注。可以计算报价区间的歧义保留待确认；没有对应规则或无法确定扣费金额的项目按0计算，不影响其他已知项目正常扣费，也不单凭缺少扣费规则拒绝商品。保留待确认依据，并按当前推送配置处理。电池互斥分档不累加；多个可计价的冲突备注保留区间并标待确认。

自动扣费覆盖港澳/海外版本、组合颜色、屏幕/电池更换及部件类型、鼓包、后摄更换、镜头水印/彩点/蓝光、屏幕老化、原彩及缺少全套配件等已明确报价条件。港版/香港版按港澳别名识别；港澳专项与普通水货费用互斥。独立条件累计扣费，同一部件类型互斥，不按别名重复扣。部件类型未说明时，保留同机型报价中的可能扣费区间，按用户选择的较低扣费端计算参考上限与推送门槛，状态仍待确认。明确的原装更换屏、第三方电池等按相应报价项处理。

容量本身只选择该容量的指导价，不另扣费；例如「256G蓝色-300」同时要求该容量与蓝色，不能套用到其他容量或其他颜色。成色限定备注只对其指定档位生效；电池多档备注与转引「低于70%按弹电」使用本机型、所选类别的实际报价金额。读取报价时在内存中重组断行并保留手工规则身份，不改写历史评估；事实提取与计价版本更新后，新评估使用补齐的规则。

扣费为区间时计算回收价上下界：保守端也符合才能明确命中；只有乐观端符合则待确认，超过乐观上限则不推。无明确上限的扣费不声称确定回收价。

## 可选 AI

默认关闭。开启后发送商品标题、描述、参数、页面价格和成色规则，使用兼容 Chat Completions 的接口。Key 保存于本地忽略的 `.env`，业务接口不回传。

每项模型事实必须带原文连续片段；校验电池数字、容量、机型。AI不能抹掉本地明确识别的故障，也不能因电池/拆修未写而改变缺省正常口径。模型调用或校验失败重试一次，仍失败则保留本地结果为待确认，明确标注“AI复核失败”。原文没有读到时记录失败，不推送。

## 推送和复核

普通命中以机型容量为标题，正文先展示商品标题、挂牌价与按描述判断的成色、扣费后回收估值及价差；只有实际扣费时才展开基础价和扣费，地区与卖家合并一行，随后提供官方链接和报价参考。待确认商品继续推送，标题保留状态前缀，使用「回收参考 ≤ …（候选上限，待确认）」或「小花参考」，不展示确定价差；所有待确认原因列表保留在网页判价依据中，不出现在推送正文。报价参考扣费表只展示项目和扣费金额，纯文本也不展示逐项扣后回收价。判价方式、通用缺省说明、完整成色依据与允许议价配置保留在运行记录和规则中，不在推送正文反复展示。

回收估值和参考上限旁明确标注扣费：固定费用显示「已扣 ¥300」，区间上限显示「按最低扣费 ¥100参考」，无上限费用显示「至少扣 ¥100」，没有应用费用显示「未扣费」；识别到问题而无对应金额时显示「无对应扣费，按0计算」。金额为本次估值实际采用的各项扣费之和，扣费明细保留基础报价与项目区间。

运行记录关联当时商品快照、规则、报价、事实和结论；后续重算不改写历史判价。可在该入口修正成色或重新判价。“验证模式”只记录，不发送通知。

命中商品页同时展示已确认与待确认候选，默认全部，可按两种状态筛选。待确认仅显示参考上限和核实原因，不展示确定价差，也不要求已推送；可从卡片右下角打开判价依据。候选升级为明确符合后合并为同一条，列表刷新保留当前筛选。命中计数仍只统计明确符合的商品，展示待确认不会改变通知配置或重复推送。

Mac 历史实现保留用于回溯，不出现在设备列表、不自动回退；未选择iPhone则暂停搜索。当前验证范围和真机边界见 [validation.md](validation.md) 第21节。

运行卡片统一使用具体原因（如价格偏高、机型不符、容量不符），另列列表筛选/详情判价/链接获取阶段；同一原因跨阶段合并筛选。已知参考上限显示为「≤ 金额」，不因成色未知把已算出的上限隐藏成「待确认」；确定金额、区间与无法计价分别显示。新记录保存当次估值快照，提前排除或取链接失败时也保留基础价、参考档位与实际扣费，可在右下角展开报价明细。历史因缺少扣费被拒绝的记录标为「旧策略未计价」，缺失金额或档位不以当前设置倒推。
